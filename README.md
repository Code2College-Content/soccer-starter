# County Youth Soccer League: fall sign ups (practice project)

Client: Terrence Boyd, volunteer league coordinator (fictional).

## The slice for Sessions 9 to 12

1. **Sign up form demo page** (signup.html): the fields Terrence asked for. Pressing the button shows a confirmation that says it is a demo and nothing was sent.
2. **One clean roster** (roster.csv) built from the three files in data/raw/, plus a **count check** (count_check.md): kids in equals kids out, and nobody in the wrong age group.
3. Stretch: a **field clash checker** that reads data/fall_schedule.csv and lists any two games on the same field at the same time.

Solo version: the clean roster and the count check only.

## What is here

* data/raw/: three sign up exports, each in a different shape
* data/age_groups.md: Terrence's age rule
* data/fall_schedule.csv: the fall game schedule (stretch)
* signup.html: stub page for the form
* count_check.md: the count check to fill in
* index.html: the team home page your link opens

## Before you start

* This repo is **public**. Everything in it is about a fictional business made up for practice.
* Never put personal information here: no real names, phone numbers, addresses or passwords.
* Never paste anything private into Copilot. Describe the columns instead of pasting rows.
* When you leave, save, commit and sync. In a Codespace, also stop it (Codespaces menu, bottom left, Stop Current Codespace). On your own laptop there is nothing to stop.

## Team rules

1. One person per file. Shared files (index.html, site.css, .github/copilot-instructions.md) change only when the team agrees.
2. Sync before you start. Commit and sync when you stop.
3. A conflict means stop and call the facilitator.
